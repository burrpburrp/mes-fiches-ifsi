# Mes fiches IFSI

Site de fiches de cours pour les étudiants en soins infirmiers (IFSI), rédigées par Oksana, avec un petit QCM à la fin de chaque fiche.

- **Oksana** : vision du produit et contenus. 👉 [Guide d'Oksana](docs/guide-oksana.md)
- **Manuel** : pilotage du projet.
- **Claude** : développement.

## Comment on travaille

- **Une idée, un besoin, un problème ?** Onglet **Issues** → **New issue**, puis choisis le formulaire.
- **Suivi de l'avancement** : onglet **Projects**, tableau « Mes fiches IFSI ».
- **Validation** : quand l'avis d'Oksana est nécessaire, la carte passe dans « À valider par Oksana » et elle est mentionnée en commentaire.

## État

Les fiches sont dans le dossier [`fiches`](fiches/), écrites avec Obsidian. Le site est publié sur GitHub Pages : https://burrpburrp.github.io/mes-fiches-ifsi/

Pour travailler sur le code : `npm install`, puis `npm run dev`.
